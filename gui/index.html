        Chain clips: each block is duration | prompt (duration in seconds, e.g. 8 | ...),
        separated by a line of =====. The first clip renders from text; each later clip is seeded
        with the last frame of the one before it. Every clip's own duration wins — the duration
        dropdown below is only used as a fallback for a block that omits N |. All other settings
        (size, steps, reuse, layers, seed) are shared by the whole chain. All clips are merged into one video
        at the end.


        Episode references (optional): attach up to 8 character/scene images above — they're
        sent with every clip. Once you attach any, first/last-frame conditioning is never used: from
        clip 2 onward, the previous clip's last frame is folded into this same reference list instead (as one
        more image, not --first-frame) — that's the reserved 9th slot. Attach none and the chain
        falls back to plain last-frame → first-frame conditioning, as before.
